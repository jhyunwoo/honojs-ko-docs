## Korean documentation work

This fork is used to study and maintain Korean-facing Hono documentation. The source site is built with VitePress and deployed through Cloudflare Pages, which makes documentation changes behave like a static web application rather than an isolated Markdown collection.

The work focuses on translating technical concepts without losing executable examples, navigation structure, or upstream conventions. Keeping the documentation buildable locally makes terminology and link changes verifiable before publication.

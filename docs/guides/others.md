# 여러 가지 잡다한

## 기여

기여 환영합니다! 다음과 같은 방법으로 기여할 수 있습니다.

- 이슈 생성 - 새로운 기능을 제안합니다. 버그를 신고하세요.
- Pull Request - 버그와 오타를 수정했습니다. 코드를 리팩터링합니다.
- 타사 미들웨어 생성 - 아래 지침을 따르세요.
- 공유 - 블로그, X(트위터) 등을 통해 여러분의 생각을 공유해보세요.
- 신청하세요 - Hono를 사용해 보세요.

자세한 내용은 [투고 가이드](https://github.com/honojs/hono/blob/main/docs/CONTRIBUTING.md)를 참조하세요.

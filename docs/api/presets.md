# 사전 설정

Hono에는 각각 특정 목적을 위해 설계된 여러 라우터가 있습니다.
Hono 생성자에서 사용하려는 라우터를 지정할 수 있습니다.

**사전 설정**은 일반적인 사용 사례를 위해 제공되므로 매번 라우터를 지정할 필요가 없습니다.
모든 사전 설정에서 가져온 `Hono` 클래스는 동일하며 유일한 차이점은 라우터입니다.
따라서 서로 바꿔서 사용할 수 있습니다.

## `hono`

용법:

```ts twoslash
import { Hono } from 'hono'
```

라우터:

```ts
this.router = new SmartRouter({
  routers: [new RegExpRouter(), new TrieRouter()],
})
```

## `hono/quick`

용법:

```ts twoslash
import { Hono } from 'hono/quick'
```

라우터:

```ts
this.router = new SmartRouter({
  routers: [new LinearRouter(), new TrieRouter()],
})
```

## `hono/tiny`

용법:

```ts twoslash
import { Hono } from 'hono/tiny'
```

라우터:

```ts
this.router = new PatternRouter()
```

## 어떤 사전 설정을 사용해야 합니까?

| 프리셋       | 적합한 플랫폼                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hono`       | 이는 대부분의 사용 사례에 적극 권장됩니다. 등록 단계는 `hono/quick`보다 느릴 수 있지만 부팅되면 높은 성능을 발휘합니다. **Deno**, **Bun** 또는 **Node.js**로 구축된 수명이 긴 서버에 이상적입니다. 해당 플랫폼의 앱 빌드 단계에서 경로 등록이 발생하므로 **Fastly Compute**에도 적합합니다. v8 격리가 활용되는 **Cloudflare Workers**, **Deno Deploy**와 같은 환경의 경우에도 이 사전 설정이 적합합니다. 부팅 후 일정 시간 동안 격리가 지속되기 때문입니다. |
| `hono/quick` | 이 사전 설정은 모든 요청에 ​​대해 애플리케이션이 초기화되는 환경을 위해 설계되었습니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `hono/tiny`  | 가장 작은 라우터 패키지로 리소스가 제한된 환경에 적합합니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
